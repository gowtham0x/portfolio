Case Study · 2024

Wireless Intrusion Detection System

An ML-powered wireless intrusion detection system using Random Forest classification and SMOTE oversampling on the AWID dataset — achieving high-precision detection of 802.11 network attacks.

RoleSecurity Researcher & ML Engineer
Timeline2024
FocusMachine Learning · Network Security · Python
WIDS

Context

Wireless networks are a prime attack surface — evil twin attacks, deauthentication floods, injection attacks. The AWID (Aegean Wi-Fi Intrusion Dataset) provides labelled 802.11 traffic captures. This project applies machine learning to build a real-time-capable intrusion detection classifier.

The Problem

Class imbalance in network traffic datasets (attacks are rare compared to normal traffic) causes models to overfit to the majority class and miss attacks. The challenge: build a classifier that detects attack traffic with high precision and recall despite severe class imbalance.

Process

01

AWID dataset preprocessing

Cleaned and normalised the AWID dataset — handling missing values, encoding categorical features, and preparing 802.11 frame attributes for ML ingestion.

02

SMOTE oversampling

Applied Synthetic Minority Oversampling Technique (SMOTE) to balance attack-class samples against the majority normal-traffic class, preventing the model from ignoring rare attacks.

03

Feature selection

Used feature importance from an initial Random Forest to identify the most discriminative 802.11 attributes, reducing dimensionality without losing detection accuracy.

04

Model training & evaluation

Trained Random Forest classifier; evaluated using Precision, Recall, F1-score and ROC-AUC across attack categories.

Design Decisions

Random Forest over deep learning

Random Forest is interpretable, robust to noise, and works well with tabular network data. Explainability matters in security — a model you can't explain is a model you can't trust.

SMOTE over class weighting

SMOTE generates synthetic minority samples that better capture the distribution of attack traffic, outperforming simple class-weight adjustments in precision/recall balance.

Outcome

✦ High precision and recall on AWID attack categories

✦ Effective class imbalance handling via SMOTE

✦ Interpretable feature importance for attack analysis

✦ Strong ROC-AUC across multiple 802.11 attack types

✦ Research-grade evaluation methodology

Reflection

“This project showed me that security and machine learning share the same adversarial mindset. The model doesn't just classify — it reasons about what normal looks like so anomalies become visible.”
